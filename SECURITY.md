# Security Policy

## Scope & Privacy Commitment

OpenKey is an input method engine for macOS. Because an input method processes keystrokes, security and user privacy are treated with the highest priority:

* **Zero Telemetry / Keylogging:** OpenKey does not log keystrokes, transmit text over the network, or store private typing data.
* **Open & Verifiable:** All source code is 100% open-source under GNU GPL. You can audit and build the application directly from source.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest release (`main`) | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability or privacy concern in this project:

1. **Do not create a public issue.**
2. Send an email to the repository maintainer or submit a Private Vulnerability Report via GitHub Security Advisories (`Security` tab -> `Report a vulnerability`).
3. Include detailed steps to reproduce, impact assessment, and proof of concept if available.

We will acknowledge receipt within 48 hours and work with you to release a patch promptly.
